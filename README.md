# 곁 GYEOT — 서비스 소개 페이지

고령층이 온라인 건강식품 광고 앞에서 식약처 공식 근거로 스스로 판단하도록 돕는 AI 소비 동행 서비스, 곁(GYEOT)의 서비스 소개 페이지입니다. 곁은 기획 단계의 서비스로, 아직 운영하고 있지 않습니다.

- `index.html` · `styles.css` · `main.js` — 빌드 과정 없는 정적 사이트
- `og.png` — 링크 미리보기 이미지(1200×630)
- 외부 리소스: Pretendard(OFL-1.1, jsDelivr), Lucide 아이콘(ISC, jsDelivr)
- 모든 화면은 이해를 돕기 위한 예시이며, 제품명·인물·채널명·주소는 가상입니다. 카카오톡은 (주)카카오의 상표이며 이 페이지는 카카오와 관련이 없습니다. 곁은 식품의약품안전처·식품안전나라와 관련이 없는 민간 서비스입니다.

로컬에서 보기: `index.html`을 브라우저로 엽니다. 주소 끝에 `?static`을 붙이면 등장 효과 없이 모든 내용이 바로 표시됩니다(캡처·인쇄용).

배포할 때: `index.html`의 `og:image`·`twitter:image`는 GitHub Pages 주소(`https://junseo0im.github.io/gyeot-site/og.png`)를 기준으로 합니다. 다른 곳에 배포하면 실제 주소로 바꿔 주십시오.
